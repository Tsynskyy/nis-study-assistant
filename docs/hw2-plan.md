# ДЗ 2. Анализ вариантов и план реализации

## Варианты

| Вариант | Плюсы | Минусы | Вывод |
| --- | --- | --- | --- |
| Загрузить файлы в ChatGPT/Claude Projects | ноль кода, хорошее качество | данные уходят в облако; ручная перезагрузка после каждого обновления; нельзя измерить качество | не подходит по ограничениям |
| n8n: workflow "файлы -> векторная БД -> LLM" | быстро собрать, визуальный пайплайн | нужен сервер n8n, векторная БД и LLM-API; сложно версионировать и тестировать | избыточно для 125 фрагментов |
| LangChain / LangGraph + эмбеддинги (multilingual-e5) + Chroma | стандартный стек, семантический поиск | тяжелые зависимости (torch, ~2 ГБ), долгий холодный старт | рассмотреть как улучшение |
| Свой легкий RAG: лексический поиск (BM25) + маршрутизатор + опциональная LLM | без зависимостей, мгновенный, полностью воспроизводимая оценка | хуже понимает перефразы и синонимы | **выбран для MVP** |

Почему так: корпус маленький и терминологичный (названия курсов, "ДЗ", "дедлайн"), поэтому лексический поиск должен давать приемлемое качество
Самая частая потребность - дедлайны, а это структурированные данные: их правильнее выбирать фильтром по дате ("инструмент" агента), чем семантическим поиском

## Архитектура MVP

```
вопрос -> маршрутизатор -+- «дедлайн»: инструмент дедлайнов (CSV, фильтр по дате и курсу)
                         +- иначе: ретривер (топ-3 фрагмента) -> порог уверенности
                                                                 +- ниже: «не нашел»
                                                                 +- выше: генерация
генерация: локальная LLM в Ollama по фрагментам, иначе извлечение лучшего фрагмента
каждый запрос -> logs/queries.jsonl
```

## Что сравниваем в ДЗ 3

1. Ретриверы: пересечение слов (baseline), TF-IDF, BM25
2. С маршрутизатором дедлайнов и без него
3. Параметры: длина префикса при стемминге (4/5/6), порог уверенности

## Оценка качества

Размеченный набор `eval/questions.jsonl`: 24 вопроса по сценариям 1-4 с ожидаемой строкой в правильном фрагменте и 4 вопроса вне темы
Метрики: hit@1, hit@3, MRR, доля правильных ответов (найдено и уверенно), точность отказов, задержка

## План и оценки

| Этап | Результат | Оценка времени |
| --- | --- | --- |
| Загрузка и нарезка источников | `corpus.py`, 125 фрагментов | 2 ч |
| Три ретривера и маршрутизатор | `retrieval.py`, `pipeline.py` | 3 ч |
| Размеченный набор и оценка | `eval/`, `evaluate.py` | 2 ч |
| Итерация по результатам | лучший вариант по метрикам | 2 ч |
| Журнал, мониторинг, тесты | `monitor.py`, `tests/` | 2 ч |
| Отчеты | `docs/` | 2 ч |

Итого около 13 часов
Ожидаемое качество: BM25 + маршрутизатор - hit@3 ~ 0,8-0,9 на размеченных вопросах; на свободных формулировках ниже, это проверит ДЗ 5
