# ДЗ 1. Постановка задачи

## Проблема

Учебная информаация разбросана по огромному количеству источников: Smart LMS, старая LMS, Т-Образование, чаты курсов в Telegram, письма менеджеров, Google таблицы с расписанием
Цель - ассистент, который отвечает на такие вопросы за секунды, со ссылкой на источник, и честно говорит не знаю, когда ответа в материалах нет

## Пользователь

Один пользователь
Короткие разговорные запросы на русском - что мне сдавать на этой неделе
Работа из терминала, рядом с существующим CLI парсера

## Сценарии использования

1. **Ближайшие дедлайны** "Что сдавать на этой неделе?" -> список будущих сроков по дате со всех платформ
2. **Дедлайн конкретного курса** "Когда ДЗ по логированию в SRE?" -> дата и название
3. **Правила оценивания** "Формула оценки по экономике?", "Сколько баллов по БКС?"
4. **Организационные факты** Кто ведет курс, где записи пар, что с оценкой за практику
5. **Вопрос вне материалов** "Погода в Москве" -> явный отказ

## Данные

| Источник | Формат | Объем | Обновление |
| --- | --- | --- | --- |
| Сводка семестра `AUTUMN-2026.md` | Markdown | ~500 строк | вручную после писем и чатов |
| Сводка курса `SRE-2026.md` | Markdown | ~100 строк | вручную |
| Сводка LMS `LMS.md` | Markdown | ~70 строк | парсер |
| Дедлайны Smart LMS `lms_deadlines.csv` | CSV | 25 строк | парсер |
| Задания Т-Образования `tbank_tasks.csv` | CSV | 46 строк, 32 со сроком | парсер |
| Реестр курсов семестра `autumn_2026_courses.csv` | CSV | 9 строк | вручную |

После нарезки получается 125 фрагментов
В индекс намеренно не входят договоры, платежи и реестр проблем: они не нужны для сценариев и чувствительны

## Ограничения

- Данные персональные: в репозиторий ассистента не копируются, читаются по пути из переменной окружения; журнал запросов локальный
- Все должно работать без интернета и без платного API
  LLM - опционально
- Ответ только по материалам; без источника ответа нет
- Даты относительные ("на этой неделе"), поэтому нужен учет текущей даты
- Время на реализацию - несколько дней

## Требования

Функциональные:
- CLI: один вопрос и диалог
- Ответ содержит источник (файл и раздел или строку выгрузки)
- Дедлайны берутся из структурированных CSV по дате, а не "по похожести текста"
- Вне материалов - отказ

Нефункциональные и целевые метрики:

| Метрика | Цель |
| --- | --- |
| hit@3 на размеченных вопросах (нужный фрагмент в топ-3) | >= 0,8 |
| Доля правильных отказов на вопросах вне темы | >= 0,75 |
| Задержка поиска p95 без LLM | < 2 с |
| Доля отказов в эксплуатации | <= 20 % |
| Возраст данных | <= 7 дней |
